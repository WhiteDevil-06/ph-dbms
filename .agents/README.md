# Team Roles and Agent Instructions Directory

This directory contains authoritative, human-readable role briefs for the three team members collaborating on the **Intelligent Data Management and Operational Analytics for Autonomous Post-Harvest Material Handling Systems** DBMS project.

## Directory Structure
```text
.agents/
├── README.md                           # This overview file
└── roles/
    ├── RAKSHITH_RAGHAVENDRA.md         # Project Lead & Database Architect
    ├── RAMCHARAN.md                    # Frontend & Dashboard Developer
    └── RAHUL.md                        # Backend & Database Integration Developer
```

## How to Use These Role Files
When working in an AI-assisted IDE (Google Antigravity, Codex, etc.):
1. Each team member copies the designated prompt located at the bottom of their respective role file into their chat session.
2. The agent reads the root `AGENTS.md` first, followed by the member's role file and designated reading list.
3. The agent acts strictly within the stated module ownership and must not infringe on teammate responsibilities.
